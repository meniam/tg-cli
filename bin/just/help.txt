    tg-cli (working name): a console tool for a personal Telegram account.
    Its main user is an AI agent. A persistent daemon holds the connection and
    the session; the CLI and agents talk to it over JSON-RPC. The project is in
    early development.

  Capabilities
    Build the binary, run it, check formatting, static analysis and tests,
    and tidy the Go dependencies.

  Build and run
    just build                  Build the binary into dist/tg
    just run <arguments>        Run the tool without building

  Checks
    just fmt                    Format the code with gofmt
    just vet                    Static analysis with go vet
    just test                   Run the tests
    just check                  Format check, vet and tests in a row, as before a commit

  Maintenance
    just docs                   Rebuild generated CLI documentation tables
    just tidy                   Tidy go.mod and go.sum
    just clean                  Remove build output from dist/

  Run just check before every commit.

  Help for a command: -h or --help after it, for example just check -h
  Full recipe list: just --list
