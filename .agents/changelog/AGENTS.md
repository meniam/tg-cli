# Changelog

Записи об изменениях, видимых снаружи кода: один файл на запись, frontmatter и
одна строка текста. Правила: [changelog.md](../rules/changelog.md).

- Текущий месяц лежит в корне папки, прошлые в подпапках `YYYY-MM/`.
- Читай через `just changelog list` (флаги `--days`, `--all`, `--type`, `--breaking`),
  папку целиком не открывай. Искать запись можно через `grep` по папке.
- Добавляй запись рецептом `just changelog add`, руками файлы не создавай.
- Файл прошлого месяца не правят и не переносят вручную.
