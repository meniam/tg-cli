# Веб-сервер работает отдельным процессом и вызывает методы демона по белому списку

## Decision

`tg web` отдаёт встроенный интерфейс и ходит в демон через Unix-сокет.
По умолчанию он слушает `127.0.0.1` и ищет порт с 1313 по 1412.
URL при запуске содержит одноразовый для процесса секрет во фрагменте,
который браузер обменивает на HttpOnly cookie. Шлюз проверяет Host и
Origin, а для записи настроек также требует cookie и специальный заголовок.

История и поиск читаются локально. События идут через SSE из подписки на
журнал демона. Миниатюры запрашиваются отдельно через общий дроссель.
Шлюз пропускает только предусмотренные методы чтения и настройки чатов.

## Why

Отдельный процесс позволяет закрыть интерфейс, оставив сессию и фоновые
задачи в демоне. Белый список закрывает команды записи сообщений независимо
от настроек аккаунта.

## Cost

Веб-интерфейс зависит от сохранённых данных. Если локальная история
неполна, её нужно догрузить отдельно. Явная привязка к сетевому IP
передаёт данные по HTTP без шифрования.
