# Прерванный перенос базы доводится сам, если обе копии побайтно совпадают

## Context

Решение [базы данных лежат в db рядом с конфигом](20261116_0136_databases_live_in_db_next_to_the_config.md) требовало код 2, если база есть в обоих местах. Авария между `rename` и удалением старого файла давала именно это состояние навсегда, пока владелец не удалит файл руками.

## Decision

Если в обоих местах лежат файлы с одинаковым `sha256`, у старого пустой `-wal` и копия проходит `integrity_check`, старый файл удаляется и перенос завершается. Разные файлы или непустой `-wal`: код 2, оба файла целы.

## Why

- Совпадение хеша доказывает, что новая копия полная, потерять нечего.
- Отвергнуто: код 2 при любых двух файлах. Ручной шаг после редкой аварии.
- Решение принял менеджер по поручению владельца.

## Cost

- Ещё одно чтение базы (21 МБ у владельца) на старте в этом редком состоянии.
