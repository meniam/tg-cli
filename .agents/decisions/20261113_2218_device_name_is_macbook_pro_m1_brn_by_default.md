# Имя устройства по умолчанию MacBook Pro M1 BRN, --device переопределяет

## Context

Без настройки `gotd/td` отправляет Telegram данные об устройстве: модель
`go1.27.4` (версия Go), систему `darwin`, версию приложения равную версии
библиотеки, языковой пакет пустой (проверено в исходниках библиотеки). Владелец
увидел в списке устройств Telegram клиент «go1.27.4» и сообщил, что хочет
видеть вместо него «MacBook Pro M1 BRN».
[Решение про пресеты](20261113_2116_login_uses_official_client_presets.md)
оставляло эти данные по умолчанию.

## Decision

- Модель устройства по умолчанию `MacBook Pro M1 BRN`
  (`tgclient.DefaultDeviceModel`).
- `daemon start --device <имя>` переопределяет её. Имя от 1 до 64 символов без
  управляющих. Заданное флагом имя запоминается в `<каталог профиля>/device`
  (права 0600), следующий запуск обходится без флага.
- Меняется только модель устройства. Версия ОС, версия приложения и языковой
  пакет остаются значениями `gotd/td` по умолчанию.

## Why

- Список устройств Telegram показывает модель, и владельцу нужно узнавать
  сессию своей утилиты и при необходимости закрывать её.
- Отвергнуто: подставлять данные официального клиента (модель «Desktop», ОС
  «Windows 10», языковой пакет `tdesktop`) из файла пресетов. Это прямая
  имитация чужого приложения, выгода не доказана.
- Отвергнуто: общее имя `tg-cli`. Владелец выбрал своё.

## Cost

- Имя `MacBook Pro M1 BRN` записано в коде как значение по умолчанию: оно
  личное, у другого владельца утилиты его придётся менять флагом или константой.
- Несостыковка остаётся: приложение называется «Telegram Desktop» (по
  `api_id` пресета), а устройство «MacBook Pro M1 BRN» с версией библиотеки
  gotd. Что из этого не проверено на живом аккаунте: см.
  [FEATURES.md](../../FEATURES.md) 1.13.
