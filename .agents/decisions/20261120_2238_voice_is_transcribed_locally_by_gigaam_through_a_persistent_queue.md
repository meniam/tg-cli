# Голосовые, кружки и видео расшифровывает локальная модель GigaAM через постоянную очередь

## Context

Команда `tg message transcribe` просит расшифровку у Telegram (`messages.transcribeAudio`):
нужен Premium, видео Telegram не расшифровывает, а автоматический вызов на каждое
голосовое нагрузил бы Telegram API. В базе владельца 2026-11-20: `voice` 356 (238 в личных
чатах), `video_note` 58, `video` 3 471, строк в `transcriptions` 0. Владелец потребовал:
расшифровывать входящие и при синхронизации чата, гнать всё через локальную модель, не
нагружать Telegram API и работать через очередь.

## Decision

- Движок: GigaAM v3 (Сбер, MIT) через внешнюю программу `sherpa-onnx-vad-with-offline-asr`
  и `ffmpeg`, без cgo, по образцу проекта stenograf. Программа запускается без оболочки с
  фиксированными аргументами, `stdout` и `stderr` читаются раздельно.
- Установка `tg voice install`: архивы только по закреплённым в коде ссылкам и SHA-256,
  проверка суммы до распаковки, распаковка без выхода за каталог, файлы в
  `<home>/models/gigaam/`, один набор на все профили. `ffmpeg` берётся из `PATH` или из
  `[voice_transcription] ffmpeg`, при отсутствии очередь встаёт с причиной `engine_missing`.
- Очередь это таблица `voice_queue` в `store.db` (приоритеты 0 ручная, 10 входящая, 20
  синхронизация, 30 backfill), один рабочий на демон, `running` после падения возвращается
  в `queued`. Метки чатов лежат в `voice_chats`, ставятся `tg chat voice on|off`.
- `messages.transcribeAudio` автоматически не вызывается: только по явному
  `tg message transcribe --telegram`. Без `[voice_transcription] enabled = true` источники
  не ставят заданий.
- Русский движок на нерусской речи даёт мусор: расшифровываем как есть и предупреждаем в
  документах. Свои исходящие голосовые не расшифровываются. Синхронизация ставит только
  сообщения младше 90 дней, остальное по `--backfill`.

## Why

- Telegram: платно (Premium), не берёт обычное видео, нагрузка на API без пределов.
- Whisper как движок: тяжелее и медленнее на русском; второй движок вне объёма.
- cgo-привязка к sherpa-onnx: ломает чистую сборку без cgo; внешняя программа проще и
  заменяема.
- Очередь в базе, а не в памяти: переживает перезапуск, видна в статусе, не теряет задания.
- Модель в общем каталоге: около 190 МБ, одинакова для профилей.

## Cost

- Нужны `ffmpeg`, около 190 МБ рантайма и модели, ручной `tg voice install`.
- Скорость GigaAM на этой машине не измерена (владелец выбрал вариант без спайка); пределы
  пересматриваются по первой живой расшифровке.
- Миграция схемы необратима для старых бинарников: копия базы перед деплоем.
- GigaAM только русский: чужая речь попадает в поиск мусором.
