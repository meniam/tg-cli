# Корень баз это каталог конфига плюс db, без своего ключа и переменной

## Decision

Корень баз вычисляется как `filepath.Dir(<путь конфига>)/db`. Ключа в конфиге и переменной окружения для него нет. `ResolvePaths` получает корень параметром, пустой корень: ошибка.

## Why

- Так владелец просил: база рядом с конфигом, в подпапке `db`.
- Тесты подставляют путь конфига во временный каталог и не попадают в настоящий `~/.config`.
- Отвергнуто: отдельный ключ `db_home`. Ещё одна настройка, которой никто не просил.
- Решение принял менеджер по поручению владельца.

## Cost

- Корень баз нельзя сдвинуть отдельно от конфига; для этого нужен другой путь конфига.
