# Команда schema описывает команды, классы безопасности и поля ответов

Decided: 2026-11-14
Revised: —

## Context

Агент должен узнавать возможности утилиты от неё самой (пункт 3.8 в
`FEATURES.md`, [INTENT.md](../../INTENT.md)), а у каждой команды должен быть
признак «опасная» (3.8.2). Открытый вопрос «что считать опасным» ещё не решён
целиком. `--fields` (3.4) бесполезен, если агент не знает, какие поля бывают.

## Decision

- `tg-cli schema` печатает машинное описание без Daemon и без сети: версия
  схемы, имя и версия утилиты, глобальные флаги, команды (путь, краткое и
  полное описание, аргументы с признаками «обязателен» и «любое число»,
  флаги с типом, значением по умолчанию, допустимыми значениями и
  повторяемостью), коды выхода и форматы вывода.
- У каждой команды класс безопасности: `read` (только читает), `local_write`
  (пишет в локальную базу), `account_write` (меняет аккаунт Telegram), и
  отдельный признак `dangerous`, который ставится явно у каждой команды, а не
  выводится из класса (пример: `note delete --author ai --yes` это
  `local_write`, но опасная).
- Поля ответа каждой команды в схеме собираются из Go-типов результата через
  теги `json` (путь, тип, признак «необязательное»); команда помечена типом
  результата. Тест не даёт добавить команду без класса, признака `dangerous` и
  типа результата.
- `--fields a.b,c` фильтрует `data` по путям: для списков применяется к
  каждому элементу, для JSONL к каждой строке; путь, которого нет в ответе,
  молча пропускается (необязательные поля иногда не приходят), конверт ошибки
  не меняется.

## Why

- Схема из кода и тест полноты не устаревают, ручное описание устарело бы при
  первой правке типа.
- Три класса различают риск чтения, записи в базу и изменения аккаунта; один
  булев признак их бы смешал.
- Отвергнуто: четыре класса с отдельным `destructive`: граница с
  `account_write` вкусовая, отправленное сообщение тоже нельзя вернуть.
- Отвергнуто: без списков полей ответа: `--fields` вслепую.
- Отвергнуто: списки полей вручную: устаревают незаметно.

## Cost

- Рефлексия по типам нетривиальна для вложенных структур и срезов, нужен
  аккуратный код и тесты.
- Класс безопасности и `dangerous` расставляются людьми: ошибка в пометке не
  ловится тестом (он проверяет только наличие).
- Агенты начнут опираться на классификацию, менять её потом дорого.
