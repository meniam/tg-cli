# HTTP-шлюз tg web разрешает только чтение

## Context

Владелец ограничил переделку веб-клиента режимом чтения. Прежний шлюз
допускал изменение настроек по сессионной cookie и специальному заголовку.

## Decision

HTTP-шлюз передаёт демону только заранее перечисленные методы чтения.
Остальные методы получают 403 до обращения к демону. Через браузер
доступны сведения о чате, режим загрузки истории и политика доступа.
Для миниатюр действует существующий кэш демона и ограничения `downloads`.

## Why

Правило действует на границе HTTP и охватывает запросы из интерфейса и
прямые запросы к шлюзу. Доступ к данным проверяет демон.

## Cost

Изменение настроек остаётся за пределами веб-интерфейса. Для возврата
записи в браузер потребуется новое решение.
