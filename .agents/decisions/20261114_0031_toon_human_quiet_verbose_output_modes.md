# Форматы вывода: toon и human рядом с json, режимы quiet и verbose

Decided: 2026-11-14
Revised: —

## Context

Сейчас каждая команда печатает один JSON-конверт, у списков есть JSONL. В
`FEATURES.md` ещё есть TOON (3.3) и режимы `--human`, `--quiet`, `--verbose`
(3.5). TOON (Token-Oriented Object Notation) это компактный текстовый формат
для тех же данных, у него есть реализация на Go: `github.com/toon-format/toon-go`
v1.0.1 (MIT, спецификация 4.4, тесты на примерах спецификации, пометка
«community-driven»). Замер 2026-11-14 на формах наших ответов (размер в
байтах, токены не измерялись): список из 50 чатов 5021 байт в JSON, 5345 в
TOON как есть (на 6% хуже, пропущенные необязательные поля делают элементы
разными и табличный вид не применяется), 3201 после выравнивания полей (на
36% меньше); страница из 20 сообщений 3604, 3965 и 2546 (на 29% меньше).

## Decision

- Формат выбирается глобальным флагом `--format json|jsonl|toon|human`, по
  умолчанию `json`. `jsonl` допустим только для команд-списков (иначе код
  выхода 2). `--human` это короткая запись `--format human`.
- `toon`: весь конверт (и успех, и ошибка) кодируется библиотекой `toon-go`;
  перед кодированием у объектов в массивах выравниваются ключи (пропавшие
  становятся `null`), чтобы сработал табличный вид.
- `human`: один общий форматтер на все команды: объект строками «ключ:
  значение», список объектов таблицей из первых колонок с обрезкой длинных
  значений, ошибка одной строкой с кодом выхода; без форматтера на каждую
  команду.
- `--quiet` убирает из stderr подсказки и ход выполнения (предупреждение о
  пресете, строки «Requesting…», «Signing in…»), `--verbose` добавляет
  диагностику (путь сокета, время вызова); ни один режим не печатает тексты
  сообщений, названия, секреты.
- Код ответа и stdout для `json` и `jsonl` не меняются.

## Why

- TOON даёт ощутимую экономию на списках, а готовая библиотека делает работу
  небольшой.
- Один форматтер `human` стоит почти ничего и работает для будущих команд.
- Отвергнуто: откладывать TOON. Токены на списках дороже, добавлять потом не
  проще.
- Отвергнуто: своя реализация TOON. Готовая проверяется спецификацией.
- Отвергнуто: форматтер `human` на каждую команду: около двадцати команд,
  каждая правка ответа требует правки двух мест.

## Cost

- Зависимость от библиотеки не из основной команды формата; спецификация ещё
  развивается, версия может смениться.
- Другие программы читают JSON лучше, чем TOON, поэтому `json` остаётся
  умолчанием.
- Точность чтения TOON моделями относительно JSON мной не проверялась.
- Выравнивание добавляет `null` в TOON-ответ; выигрыш в токенах (не в байтах)
  на реальных данных не измерен.
