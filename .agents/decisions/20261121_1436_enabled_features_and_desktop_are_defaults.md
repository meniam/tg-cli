# Фоновая загрузка, векторный поиск и расшифровка голоса включены по умолчанию, пресет desktop выбран по умолчанию

## Context

Владелец использует инструмент для личного аккаунта и выбрал новые умолчания вместо ручного включения функций и выбора клиента.

## Decision

- Фоновая загрузка, семантический поиск и локальная расшифровка голоса включены по умолчанию.
- Суточный бюджет загрузки голоса составляет 5000 МиБ и 500 файлов.
- Если пресет не задан флагом, переменными приложения или настройкой базы, используется `desktop`.
- Флаг `--client` и собственные `TG_API_ID` и `TG_API_HASH` одновременно остаются ошибкой. Сохранённые значения не заменяются новыми умолчаниями.

## Why

Владелец выбрал эти значения для личного инструмента, чтобы обычные рабочие функции были доступны без отдельной настройки каждого нового профиля.

## Cost

Новая установка сама обращается к Telegram в фоновом режиме, запускает индексатор Ollama и обрабатывает голос. Возможны сетевой трафик, вычислительная нагрузка и задержки. Эти функции можно выключить настройками.
