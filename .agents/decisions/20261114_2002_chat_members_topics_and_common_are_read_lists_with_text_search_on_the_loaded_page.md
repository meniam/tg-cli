# Участники, топики и общие чаты читаются тремя командами под chat: текст поиска вместе с фильтром роли применяется к загруженной странице, закрытые чаты убираются из общих с добором страниц, канал без прав админа даёт ошибку, люди сохраняются в people

Decided: 2026-11-14
Revised: —

## Context

Агент не мог прочитать, кто состоит в чате, какие темы есть у форума и какие чаты общие с человеком. Аудит шага 1 плана (по коду gotd, на живом аккаунте не проверялся):

- `channels.getParticipants` принимает один фильтр: `Recent`, `Admins`, `Bots` или `Search{Q}`. Роль и текст одним запросом не выбрать.
- Обычная группа отдаёт список целиком (`messages.getFullChat`), страниц у Telegram нет.
- `messages.getCommonChats` листает по `max_id`, а закрытые чаты (списки `allow` и `block` в `access.json`) в ответе придут вместе с открытыми.
- Курсор истории `{v,c,i}` хранит чат и id сообщения; темам нужны дата, id сообщения и id темы, общим чатам нужны пользователь и сырой id чата.
- `CHAT_ADMIN_REQUIRED` в `notFoundErrors` не входит и даёт код 5; `CHANNEL_PRIVATE`, `CHANNEL_INVALID` и `USER_ID_INVALID` дают код 7.

## Decision

- Команды `tg chat members <chat> [--search T] [--offset N] [--limit 1..200, 50] [--filter recent|admins|bots]`, `tg chat topics <chat> [--limit 1..100, 50] [--cursor C]`, `tg chat common <user> [--limit 1..100, 50] [--cursor C]`. Класс `read`, методы RPC `chat.members`, `chat.topics`, `chat.common`.
- `--search` и `--filter` можно совмещать. Без `--filter` текст идёт в Telegram как `Search{Q}` и ищет по всему чату. С любым `--filter` (в том числе `recent`) роль выбирает Telegram, а текст сопоставляется по имени и `username` без учёта регистра только внутри загруженной страницы. `next_offset` считает страницу до этого отбора, поэтому страница может быть короче `--limit` или пустой при непустом `next_offset`. В обычной группе всё применяется к полному списку, порядок по `id`, поиск не ограничен страницей.
- Закрытые чаты в `chat common` убираются до ответа и до записи. Если страница после отбора пуста, а продолжение есть, Daemon читает следующую страницу, не больше десяти запросов за вызов. После десятого ответ пуст и содержит `next_cursor`; CLI пишет в stderr, что закрытые чаты скрыты, и подсказывает `--cursor`. Пользователь, которого нет в `allow` или есть в `block`, даёт `not_found`.
- `chat members` и `chat topics` для закрытого чата дают `not_found`, как неизвестный чат (`requireAllowedChat`), и запрос списка в Telegram не уходит; `@username` для проверки сначала разрешается через Telegram. Право проверяется ещё раз после ответа.
- Канал без прав админа: ошибка Telegram, код 5, `CHAT_ADMIN_REQUIRED: administrator access is required to list channel members`. Личный чат и бот дают код 2; `topics` для чата без признака форума код 2; `common` для чата вместо человека код 2; неизвестный пользователь код 7.
- Люди из `chat members` и пользователь из `chat common` пишутся в `people` (`id`, имя, `username`, признак бота), чаты из `chat common` в `chats`. Роль и дата вступления не сохраняются, таблицы членства и топиков нет. Ошибка записи в базу не ломает ответ.
- Курсоры топиков и общих чатов непрозрачные (base64url от JSON с версией `v`, как у истории): `{v,chat,date,id,topic}` и `{v,user,max_id}`. Курсор привязан к чату или пользователю; чужой или испорченный даёт код 2, а не код 8.

## Why

- Совмещение поиска и роли локально на странице, а не отказ. Агенту нужно «найти админа по имени», а Telegram одним фильтром этого не делает. Отвергнуто: код 2 при совмещении (теряем частый сценарий). Отвергнуто: обход всего списка локально (массовая выгрузка людей и много запросов на вызов; автоматический обход всего списка план исключил в разделе рисков). Цена названа ограничением в документах.
- Тихо убрать закрытые чаты и добрать страницу. Закрытый чат не должен быть виден даже косвенно (главный инвариант плана). Отвергнуто: показывать закрытые чаты (нарушает инвариант). Отвергнуто: убирать без добора (пустая страница выглядит как конец списка, агент бросит чтение). Отвергнуто: отказ с кодом при любом закрытом чате в списке (его наличие уже раскрывает факт). Предел десять запросов держит нагрузку на дроссель ограниченной.
- Ошибка для канала, а не пустой список. Отвергнуто: пустой список, он ввёл бы агента в заблуждение: «в канале никого нет» вместо «прав не хватает».
- Предел страницы участников 200, а не 100: проектное ограничение, сервер может ответить меньше. Отвергнуто: 100 (больше запросов на тот же список).
- Люди в `people`, а не только в ответе. Единообразно с правилом «всё прочитанное сохраняется», найденные люди сразу ищутся через `tg search`. Отвергнуто: не сохранять (участник, увиденный в списке, исчезал бы для поиска). Отвергнуто: таблица членства (история составов вне плана, база растёт с каждым чатом).
- Свои тела курсора на общем механизме кодирования. Курсор истории не несёт нужных полей. Отвергнуто: один формат на все списки (поля темы и общих чатов несовместимы, один формат стал бы набором необязательных полей без проверок). Отвергнуто: брать курсор истории (не вмещает дату и id темы).

## Cost

- Поиск с фильтром роли видит только страницу: имя за пределами загруженной страницы не найдётся, пока агент не пролистает `--offset`.
- `chat common` может сделать до десяти запросов за вызов и вернуть пустую страницу с `next_cursor`.
- В `people` попадают все участники запрошенных страниц; база растёт на крупной супергруппе, пока агент листает.
- Не сделано: выгрузка всех участников (FEATURES 14.1), управление участниками (7.3, 7.6), профиль пользователя (7.5), история составов.
- Верхний предел страницы участников 200 это решение проекта, а не факт gotd; сервер может отдать меньше.
- На живом аккаунте это решение ещё не проверено (шаг 6 плана): ни ответ канала без прав, ни форум, ни живой общий чат.
- Условие пересмотра: ответ живого аккаунта расходится с кодом (предел страницы, `CHAT_ADMIN_REQUIRED` у канала, смещение у `getCommonChats`), либо появился спрос на обход всех участников.
- Владелец подтвердил 2026-11-14: фильтры `--search`, `--offset` и `--filter`, сохранение людей в `people`, имена команд, совмещение поиска и фильтра, тихое убирание закрытых чатов с добором, ошибку канала без прав.
