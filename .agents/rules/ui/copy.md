# Копирование

Буфер обмена: кнопки «скопировать», двойной щелчок по ячейке, секреты.

- В буфер — только через `copyToClipboard`: он показывает нейтральный тост
  с самим значением, а при ошибке — красный. Свой `navigator.clipboard` и
  `toast()` не зовём.
- Секрет (API-ключ, значение переменной, тело вебхука) копируем с
  `preview: false`: тост без значения, секрет не всплывает на экране.
- Двойной щелчок по ячейке грида копирует её текст, как он виден, и
  показывает тост. Колонка с секретом помечается `...secretColumn()`: копия
  без значения в тосте, диалог с текстом ячейки (Alt+клик) не открывается.
  `doubleClickCopy={false}` у грида — общий выключатель, не замена метке.
- `phoneColumn` и `uuidColumn` сами копируют и открывают поповер; внутри
  ссылки — `copy={false} popover={false}`, иначе клик не дойдёт до ссылки.

```tsx
await copyToClipboard(apiKey, { message: 'Ключ скопирован', preview: false })
```

## Чек-лист

1. Копирование идёт через `copyToClipboard`, своего `navigator.clipboard` нет.
2. Секрет копируется с `preview: false`.
3. Колонка с секретом помечена `secretColumn()`.
4. `uuidColumn` и `phoneColumn` внутри ссылки — с `copy={false} popover={false}`.
