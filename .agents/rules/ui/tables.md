# Таблицы

Какую таблицу брать и как собирать `AgGrid`: сортировка, ссылки на
сущности, правка, группировка, ширина, кегль, цвет. Панель над таблицей —
`menubar.md`, фильтры — `filters.md`, колонки под тип данных — `columns.md`.

## Какую таблицу

- `AgGrid` — рабочий список и журнал (строка — объект или событие): поиск,
  сортировка, фильтры колонок, выгрузка. Даже короткий.
- `AgGrid simple` выключает сортировку, меню и фильтры, поэтому он только
  для «ключ → значение» и справочника в пару строк внутри карточки.
- `DataTable` или `Table` — таблица в несколько строк без работы со списком.

## Сортировка и меню

- Колонки сортируются, у каждой есть меню с фильтром. `sortable: false` и
  `suppressHeaderMenuButton` без причины не ставим; причина есть у меню
  действий «⋯».
- У каждой таблицы явная сортировка по умолчанию: `initialSort` в колонке, а
  не только `ORDER BY` в запросе, иначе сброс сортировки теряет порядок.
  Журнал — по времени, свежие сверху (`initialSort: 'desc'`).

## Сущности в ячейках

- Основная колонка — имя сущности строки ссылкой на её карточку
  (`linkColumn`). Связанная сущность (партнёр заказа, поставщик товара,
  склад отгрузки) — тоже ссылка на свою карточку; нет карточки — текст.
- Перед сущностью в ячейке всегда её иконка, ссылка это или текст:
  `linkColumn({ href, icon })`, в своём рендерере — `AgGridLink`. Иконка та
  же, что в заголовке колонки и в словаре (`icons.md`). `icon: null` —
  только по просьбе.
- Человек с аватаром — аватар и есть иконка, вторую не ставим.
- В ячейке-списке (товары заказа, участники) иконка или аватар у каждого
  элемента, каждый элемент — свой `AgGridLink` (`columns.md`).
- Удалённая в источнике или завершённая сущность — зачёркнутая приглушённая
  ссылка: `struck` у `AgGridLink` и `linkColumn`, а не свои классы
  `line-through`.
- У поля, которое не сущность, иконки в ячейке нет. Исключение —
  кликабельный счётчик сущностей (`numberColumn({ icon, onClick })`).

```tsx
{ ...linkColumn<Order>({ href: (o) => `/orders/${o.id}`, icon: Package,
    struck: (o) => o.cancelledAt !== null }), field: 'number', headerName: 'Заказ' }
```

## Серверный список

- Отбор, сортировку и страницу считает база, а грид показывает одну страницу:
  фильтры уходят в запрос (`filters.md`).
- Грид — `serverPage={{ sortKeys }}`: фильтры колонок выключены у всех
  колонок, сортируются только колонки, которые сортирует сервер, и в его
  порядке. `filter: false` в `defaultColDef` для этого не годится: типовые
  колонки задают свой `filter` и перебивают умолчание.
- Проп и сортировку грида из отбора даёт `serverPageProps(<SORTS>, list)`,
  `sortModel` и `onSortModelChange` руками не пишем.
- Пагинация — подвалом карточки `CardPagination` под гридом: «Страница 2 из
  5 · 120 заказов», слово склоняет `unit`. Своих блоков со счётчиком и
  кнопками не пишем.

```tsx
<CardPagination page={page} lastPage={lastPage} total={total}
  unit={['заказ', 'заказа', 'заказов']} href={(p) => ordersHref({ ...filters, page: p })}
  onGo={(p) => setFilters({ page: p })} />
```

- Курсорная лента (журнал, история событий: листается «дальше», общего
  числа строк нет) — подвал `CardCursorPagination`: «Показано: N», «В
  начало», «Дальше». Отбор — `useListFilters(<x>Filters, { cursorKey:
  'cursor' })`. Свой подвал «Загрузить ещё» не пишем.

## Меню строки

- Меню «⋯» строки — `actionsColumn({ items, name })`: пункты данными,
  обработчики через `context` грида. Переход — пункт с `href`, необратимое —
  `destructive`. Свой `DropdownMenu` в рендерере не пишем.

## Правка в ячейке

- Грид сам значение не меняет (`readOnlyEdit`): `onCellEditRequest` отдаёт
  правку серверному действию, результат показывает `notify`, строка
  перечитывается.
- Правка зависит от состояния строки — `editable` функцией.
- Булево с правкой — `switchColumn`, длинный текст — `longTextColumn`; свой
  рендерер со `Switch` не пишем.
- Что колонка правится и как — в справке её заголовка (`headerTooltip`), а
  не абзацем под таблицей.

## Группировка

- `groupDisplayType: 'groupRows'`, группы раскрыты (`groupDefaultExpanded:
  -1`), порядок групп задан `initialGroupOrderComparator` и
  `groupMaintainOrder`: сортировка колонки переставляет строки только внутри
  группы.
- «Свернуть все» и «Развернуть все» — пункты «Действий», а не кнопки
  тулбара грида.
- Пустая группа подписана с заглавной без скобок: «Без склада», а не
  «(без склада)».

## Подсказка в ячейке

- `tooltip` ячейки показывает то, чего в ней не видно: полный текст
  обрезанного значения, расшифровку кода. Значение, которое видно целиком,
  подсказкой не повторяем, и в другой записи тоже: у телефона
  `+7 (999) 123-45-67` подсказка `+7 999 123 45 67` только шумит.
- Другая запись значения, которую надо увидеть или скопировать, — поповер
  по клику и кнопка копирования, как у `uuidColumn` и `phoneColumn`
  (`copy.md`).

## Ширина и кегль

- Ширину колонки прикидывай по данным, а не по заголовку. Длинный заголовок
  в узкой колонке схлопывается в иконку, полное имя — в подсказке.
- Кегль у всех колонок один: его задаёт настройка таблицы «Размер шрифта».
  В `cellClass` и своих рендерерах `text-xs`, `text-sm`, `text-[…]` нет, даже
  у второстепенной приписки; вес — можно.

## Цвет

Много цветов дают шум, а не смысл.

- Цвет в строке несут только значок `BadgeChoice` статуса и значок булевой
  колонки. Аватар без фото красится по имени: он заменяет фото, а не
  сообщает состояние.
- Фон строки и цвет чисел (`rowClassRules`, `cellClassRules`) не трогаем,
  даже у ошибок в журнале: уровень виден по бейджу, проблемные строки
  находятся фильтром по статусу.
- Единственное, что разрешено `rowClassRules`, — приглушённый текст
  удалённого объекта (`text-text-muted`).

## Готовность

- Предупреждение AG Grid в dev-режиме (оверлей, deprecation, error #…) —
  баг: страница с ним не готова.

## Checklist

1. Список и журнал — полный `AgGrid`; `simple` только для «ключ → значение».
2. `sortable: false` и `suppressHeaderMenuButton` только с причиной.
3. Сортировка по умолчанию — `initialSort` в колонке; журнал свежими сверху.
4. Основная колонка — `linkColumn` на карточку; связанные сущности —
   ссылки.
5. Перед каждой сущностью её иконка, та же, что в заголовке и словаре.
6. Удалённое и завершённое — `struck`, без своих `line-through`.
7. Меню строки — `actionsColumn`, своего `DropdownMenu` нет.
8. Правка: `readOnlyEdit` → действие → `notify`; булево — `switchColumn`;
   подсказка о правке в заголовке.
9. Группировка: группы раскрыты, порядок зафиксирован, «Свернуть все» в
   «Действиях», пустая группа с заглавной.
10. В ячейках нет своих кеглей.
11. Нет фона строк и цвета чисел, кроме приглушённого удалённого.
12. В консоли dev нет предупреждений AG Grid.
13. Серверная пагинация — `CardPagination`, курсорная лента —
    `CardCursorPagination`, своего подвала нет; грид — `serverPage`.
14. `tooltip` ячейки не повторяет видимое значение.
