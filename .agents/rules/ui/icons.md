# Иконки

Как выбрать иконку `lucide-react` сущности и поля. Какой иконкой обозначена
каждая сущность этого проекта, знает только проект: словарь ведёт он сам.

## Одна сущность — одна иконка

- Сущность везде обозначена одной иконкой: меню, шапка страницы, заголовок
  колонки, ячейка, плитка, фильтр. Заказ в меню `Package` — значит, и в
  колонке «Заказ», и в фильтре «Заказ» тоже `Package`.
- Перед тем как взять иконку, найди сущность в словаре проекта. Нет её —
  посмотри, чем её уже обозначили (шапка её страницы, пункт меню), выбери
  по смыслу и допиши строку в словарь тем же коммитом.
- Иконка уже занята другим смыслом — выбери другую или запиши расхождение в
  словарь проекта.

## Иконка каждой колонке

Иконку подбираем каждой колонке таблицы, а не только сущности. Порядок:

1. Колонка выводит сущность (заказ, партнёр, склад) — бери иконку, которой
   сущность уже обозначена.
2. Сущности нет — по смыслу поля, а не по типу данных: «Отменено» —
   `Ban`, «Ошибок» — `CircleAlert`, «Срок поставки» — `CalendarClock`.
3. Иконка типа из типовой колонки (`Hash` у числа) остаётся, только когда
   смысл поля и есть его тип.

- Свою иконку колонке задаёт `...headerIcon(Icon)` после типовой колонки: она
  стоит только в заголовке и видна, когда подпись не влезает. У
  `linkColumn` и `listColumn` её задаёт `icon`, дубль не нужен.
- В ячейках иконка бывает у двух колонок: у сущности (`linkColumn({ icon })`,
  `listColumn({ icon })`, `AgGridLink`) и у кликабельного счётчика сущностей
  (`numberColumn({ icon })`, «товаров в заказе»). Полю иконка в ячейке не
  нужна.

## Иконки типа по умолчанию

Их ставит типовая колонка кита, если колонке не задали свою. Это запасной
вариант: поле со смыслом получает иконку по правилам выше.
Иконка типа может совпасть с иконкой сущности проекта (`Tag` у
`choiceColumn` и бренд, например): тогда такой колонке своя иконка
обязательна, а совпадение записано в словаре проекта.

| Колонка | Иконка |
| --- | --- |
| `numberColumn` | `Hash` |
| `priceColumn` | `Banknote` |
| `percentColumn` | `Percent` |
| `unitColumn` | `Ruler` |
| `durationColumn` | `Timer` |
| `sizeColumn` | `HardDrive` |
| `dateTimeColumn` | `CalendarClock` |
| `choiceColumn` | `Tag` |
| `linkColumn` | `Link2` |
| `listColumn` | своей нет: иконка сущности из `icon` |
| `idColumn` | `Hash` |
| `uuidColumn` | `Fingerprint` |
| `imageColumn` | `Image` |
| `emailColumn` | `Mail` |
| `telegramColumn` | `Send` |
| `phoneColumn` | `Phone` |
| `textMonoColumn` | `Code` |
| `slugColumn` | `Hash` |
| `boolColumn` и пресеты | `CircleCheck` |
| `switchColumn` | `ToggleRight` |
| `badgeColumn`, `longTextColumn` | своей нет: без `headerIcon` заголовок останется без иконки |

## Checklist

1. Иконка сущности взята из словаря проекта или дописана в него тем же
   коммитом.
2. Одна сущность одной иконкой в меню, шапке, колонке, ячейке, плитке и
   фильтре.
3. У каждой колонки осмысленная иконка: сущность, затем смысл поля, тип —
   последним.
4. Своя иконка колонки — `headerIcon` после типовой колонки, у `linkColumn`
   и `listColumn` — `icon` без дубля.
5. Иконка в ячейке только у сущности и кликабельного счётчика.
