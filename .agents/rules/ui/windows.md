# Окна и панели

Диалоги, выезжающие панели (`Sheet`), плашки и подтверждения.

- Крестик в углу диалога, выезжающей панели или плашки — всегда `Close`.
  `ButtonClose` — кнопка с подписью «Закрыть» в подвале формы или тулбаре;
  `ButtonCloseUtility` и `Button mode="close"` под крестик не берём.
- `ButtonCancel` — в форме с несохранёнными правками, они теряются.
  `ButtonClose` — просто закрыть, терять нечего.
- Описание выезжающей панели — `SheetInfo`: «i» после заголовка, текст в
  подсказке. Строкой под заголовком не выводим, она раздувает шапку.
- Удаление — через `Confirm`. Вариант `danger` у него по умолчанию, в
  заголовке имя объекта, а не «Удалить запись?».
- Открытое окно живёт в адресе (`useWindowState`), см. `page.md`.

```tsx
<Confirm open={open} onOpenChange={setOpen}
  title={`Удалить поставщика «${supplier.name}»?`}
  description="Заказы поставщика останутся, связь с ним пропадёт."
  onConfirm={remove} />
```

## Checklist

1. Крестик окна — `Close`.
2. `ButtonCancel` только при несохранённых правках, иначе `ButtonClose`.
3. Описание панели — `SheetInfo`.
4. Удаление — `Confirm` с именем объекта в заголовке.
5. Открытое окно восстанавливается из адреса.
