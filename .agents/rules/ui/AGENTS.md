# Правила UI

Как собираем интерфейс из кита `@/shared/ui`: страница, кнопки, окна,
списки, фильтры, колонки, иконки, графики. Правила общие для проектов
4Partners и копируются из проекта в проект как есть. Что знает только
проект (словарь иконок его сущностей, старые места, которые ещё не
выровнены), лежит в `.agents/rules/project/` и перебивает общее.

Главное правило под всеми остальными: экран собирается только из кита.
Нужного компонента, колонки или пропа нет — сначала заводим его в ките, потом
пользуемся. Свой `valueFormatter`, свой рендерер, свои классы растяжки,
цвета и кегля в фиче не пишем.

Файл читается тогда, когда задача его касается, до первой правки.

| Файл | Тема | Прочитать перед тем, как |
| --- | --- | --- |
| `page.md` | Страница: шапка, вкладки, плитки фактов, период, адрес | заводить страницу или раздел |
| `entity-card.md` | Карточка одной сущности и таблицы внутри неё | делать страницу заказа, партнёра, товара |
| `buttons.md` | Кнопки: пресеты, цвет, кнопка-иконка | ставить любую кнопку |
| `windows.md` | Диалоги, выезжающие панели, подтверждение | открывать окно или панель |
| `menubar.md` | Панель над списком `CardMenubar` | собирать список с поиском и «Действиями» |
| `filters.md` | Быстрые фильтры, `CardFilter`, `FilterSidebar`, сброс, чипы | добавлять фильтр |
| `tables.md` | `AgGrid`: каркас, сортировка, правка, группировка, цвет | собирать или менять таблицу |
| `columns.md` | Тип данных → готовая колонка кита | добавлять колонку |
| `icons.md` | Как выбрать иконку сущности и поля | ставить иконку в меню, шапку, колонку, фильтр |
| `labels.md` | Подписи значений и моноширинный шрифт | писать подпись, бейдж, пункт меню |
| `copy.md` | Копирование в буфер и секреты | давать что-то скопировать |
| `charts.md` | Графики | рисовать график |
| `states.md` | Пустое состояние и справка | делать пустой список, справку, статус |

Проект хранит у себя (`.agents/rules/project/`):

- словарь иконок своих сущностей и полей — его требует `icons.md`;
- расхождения: места, собранные до правила, которые выравнивают, когда
  трогают;
- где лежат кит, справочник кита и живые образцы.

Нет такого файла в проекте — правило действует по умолчанию, а словарь
заводится при первой новой иконке.

## Чек-лист

1. Экран собран из кита, своих форматтеров, рендереров и классов растяжки
   нет.
2. Перед правкой прочитан файл темы из таблицы выше.
3. Проектное уточнение в `.agents/rules/project/` проверено и учтено.
