# Колонки под тип данных

Какую готовую колонку `AgGrid` брать под тип данных и как выводить то же
вне таблицы. Колонки — из `@/shared/ui/AgGrid`, вне таблицы — `@/shared/ui/Format`
и `DateTime`.

Колонка задаёт разом текст, правый край, фильтр, значок заголовка, серый
ноль и то, что уходит в Excel; форматтер даёт только текст. Поэтому число,
величина с единицей, enum, имя-ссылка, флаг и меню «⋯» выводятся только
готовой колонкой, свой `valueFormatter` или `cellRenderer` под них не
пишем. Нужной колонки нет — сначала заводим её в ките.

| Данные | Колонка `AgGrid` | Вне таблицы |
| --- | --- | --- |
| Число, счётчик | `numberColumn()` | `FormatNumber` |
| Деньги | `priceColumn({ currency })` | `FormatPrice` |
| Доля 0–1 процентами | `percentColumn()` | `FormatPercent` |
| Проценты «как есть» (25.3) | `unitColumn({ unit: '%' })` | `FormatUnit` |
| Число с единицей (шт, кг, дн) | `unitColumn({ unit })` | `FormatUnit` |
| Длительность в мс | `durationColumn()` | `FormatDuration` |
| Размер в байтах | `sizeColumn()` | `FormatSize` |
| Дата, время | `dateTimeColumn()` | `DateTime` |
| Enum, статус | `choiceColumn({ options })` | `BadgeChoice` |
| Имя → карточка сущности | `linkColumn({ href, icon, struck })`, в своём рендерере `AgGridLink` | `Link` |
| Действия строки «⋯» | `actionsColumn({ items, name })` | — |
| Да / Нет (признак), свои слова | `boolTextColumn({ yes, no })` | `FormatBool` |
| Есть / Нет (наличие) | `boolHaveColumn()` | `FormatHave` |
| Флаг значком | `boolSignColumn()` | `FormatBool view="icon"` |
| Признак, где истина плохо («Забанен», «Скрыт») | пресет с `negative: true` | `FormatBool negative` |
| Булево с другим набором опций | `boolColumn({ yes, no, yesIcon, noIcon, view, colored, negative })` | `FormatBool` |
| Булево с правкой (вкл / выкл / не задано) | `switchColumn({ yes, no, unset, showText, clearable, disabled })` | `Switch indeterminate` |
| Длинный текст с правкой | `longTextColumn()` | — |
| Номер записи, id (учётка, заказ `S123`) | `idColumn({ prefix })` | `FormatId` |
| UUID | `uuidColumn()` | `FormatUuid` |
| Картинка строки: обложка, превью | `imageColumn({ alt, size })` — своя узкая колонка | `ImageThumb` |
| Email | `emailColumn()` | `FormatEmail` |
| Telegram | `telegramColumn()` | `FormatTelegram` |
| Телефон | `phoneColumn()` | `FormatPhone` |
| Моноширинный текст — только по прямой просьбе | `textMonoColumn()` | `FormatTextMono` |
| Секрет (ключ, значение переменной) | типовая колонка + `...secretColumn()` | — |
| Несколько сущностей в ячейке (проекты, теги, товары) | `listColumn({ items, label, href, icon })` | — |
| Несколько людей в ячейке | свой рендерер на `AvatarStack`, ниже | `AvatarStack` |

## Булево

- Булево рисует один `FormatBool`, колонки — пресеты `boolColumn`:
  `boolTextColumn` — «Да / Нет», `boolHaveColumn` — «Есть / Нет»,
  `boolSignColumn` — значок по центру.
- Подписи отвечают на заголовок колонки: у «Активен» — «Да / Нет», у
  «Договор» — «Есть / Нет», у «Рассылка» — «Включена / Выключена».
- Значок цветной всегда (истина зелёным, ложь красным), подпись обычная.
  `colored` красит и подпись — только по прямой просьбе пользователя;
  приводим таблицу к правилам — `colored` снимаем.
- Признак, где истина плохо («Запрещён», «Забанен», «Скрыт»), — тот же
  пресет с `negative: true`: истина красным, ложь зелёным. Подписи и значки
  не меняются, поле не переворачиваем в «Разрешён».
- Неизвестное значение (`null`) — прочерк, а не «Нет».
- В фильтр, буфер и Excel уходят подписи. Свой рендерер с «✓» или словами
  под булево не пишем, `type: 'boolean'` с чекбоксом тоже.

## Бейджи

- Бейдж в ячейке — только `mode="table"`: значок и подпись без плашки.
  `outline` и `solid` в таблицах запрещены, и в `choiceColumn`, и в своём
  рендерере.
- По умолчанию цветной только значок, подпись обычная.
  `choiceColumn({ colored: true })` красит и подпись — когда цвет и есть смысл
  значения (уровень лога, ошибка). `icon: null` в словаре убирает значок.
- Словарь enum — через `toBadgeChoiceOptions`, подписи с заглавной
  (`labels.md`).

## Числа и пустые значения

- Числа и деньги — по правому краю, в Excel уходит число, а не строка;
  готовые колонки делают это сами.
- Номер записи (id учётки, номер заказа) — не количество, а
  идентификатор: `idColumn()` ставит его слева, целым без разделителя
  разрядов, чтобы «1234» нашёлся поиском, и не приглушает ноль. Префикс
  (`idColumn({ prefix: 'S' })` → `S123`) получают и фильтр, и поиск, и
  Excel. Под номер `numberColumn` не берём: «1 234» читается как счётчик.
- Пустое значение (`null`) — прочерк `Dash`, его рисует колонка. В фильтр,
  поиск и Excel уходит пустая строка.
- Ноль выводим, только когда он задан явно. Неприменимая или неизвестная
  величина — `null` и прочерк: у отменённой отгрузки нет срока доставки,
  «0 дн» врёт.
- Настоящий ноль виден, но приглушён: глаз цепляется за ненулевые.
  `numberColumn()` делает это сам; в своём рендерере —
  `FormatNumber variant={value === 0 ? 'secondary' : 'inverse'}`.

## Свой рендерер

- Свой `cellRenderer` с `Format*`, `DateTime` или `Badge` оборачивается в
  `AgGridCell`, иначе не работает настройка размера шрифта.
- Аватар и `AvatarStack` — наоборот, без `AgGridCell`: обёртка навязывает
  кегль потомкам, и инициалы вылезают из круга.
- Текст колонки — тот же, что видно в ячейке: `valueFormatter` отдаёт его
  фильтру, буферу и Excel, `getQuickFilterText` — поиску. Иначе фильтр
  предлагает сырые значения, а поиск не находит то, что написано на экране.
- Запись, по которой ищут, но не показывают (цифры телефона подряд, код без
  дефисов), дописывается в `getQuickFilterText` через пробел к видимому
  тексту, а не заменяет его.

```tsx
valueFormatter: ({ value }) => toPhone(value)?.pretty ?? '',
getQuickFilterText: ({ value }) => {
  const phone = toPhone(value)
  return phone === null ? '' : `${phone.pretty} ${phone.digits}`
},
```

## Длинный текст

- Длинный текст (ошибка выгрузки, комментарий к заказу) — отдельной колонкой
  последней: `initialFlex: 1`, `minWidth`, полный текст в подсказке через
  `tooltip` с функцией. В одну колонку со счётчиками не склеиваем: тогда его
  не отфильтровать и не выгрузить отдельно.

## Несколько значений в ячейке

Товары заказа, теги, участники: значение колонки — массив, а не строка через
запятую. Тогда фильтр-набор перечисляет элементы поодиночке, и отметка
одного оставляет строки, где он есть. Строка через запятую даёт пунктом
фильтра каждую комбинацию целиком.

Сущности списком — `listColumn({ items, label, href, icon })`: элементы через
запятую, у каждого иконка и ссылка на карточку, без `href` — текст с той же
иконкой. Всё ниже она делает сама. Свой рендерер пишем только под людей, и
он соблюдает то же:

- `valueGetter` — массив подписей, `filter: 'agSetColumnFilter'`;
- `cellDataType: false`, иначе грид выводит тип `object`;
- `valueFormatter` и `getQuickFilterText` — те же подписи через запятую: их
  получают поиск, буфер и Excel;
- `filterParams.comparator` — по-русски, `localeCompare(b, 'ru')`;
- `sortable: false`: порядок по первому элементу ничего не значит;
- ячейку рисует свой рендерер, у каждого элемента иконка или аватар
  сущности;
- список людей — `AvatarStack`: первые `max` лицами, остальные «+N»;
  `tooltip` колонке тогда не ставим, он всплывает поверх карточки человека.

## Новая колонка в ките

Колонку заводят в ките, когда типа нет в таблице выше, а не в фиче. Одним
коммитом с ней:

- файл колонки рядом с остальными типовыми и экспорт из индекса кита;
- текст для фильтра, поиска и Excel по правилу «Свой рендерер», тест на него;
- значок заголовка `headerIcon` и строка в таблице типовых колонок `icons.md`;
- строка в таблице выше: тип данных, колонка, компонент вне таблицы;
- тип в демо колонок, с вариантами опций и сырыми данными рядом;
- запись в changelog.

## Checklist

1. Число, единица, деньги, дата, enum, ссылка, флаг, номер записи, UUID,
   email, телефон и меню «⋯» — готовой колонкой по таблице, своего
   форматтера нет.
2. Булево — пресетом по смыслу, подписи отвечают заголовку, `colored` только
   по просьбе, истина плохо — `negative`, `null` — прочерк.
3. Бейдж в ячейке — `mode="table"`.
4. Числа справа, номер записи — `idColumn` слева без разрядов; пустое —
   прочерк, ноль только заданный и приглушён.
5. Свой рендерер с `Format*` — в `AgGridCell`, аватар — без него.
6. Длинный текст — последней колонкой с `tooltip`.
7. Несколько сущностей — `listColumn`; люди — свой рендерер на
   `AvatarStack`: массив, `agSetColumnFilter`, `cellDataType: false`,
   подписи в `valueFormatter` и `getQuickFilterText`.
8. Текст колонки со своим рендерером — тот же, что в ячейке; запись для
   поиска — дописана в `getQuickFilterText`.
9. Новая колонка кита пришла с тестом, строкой в таблице, значком в
   `icons.md`, типом в демо и записью в changelog.
