# Графики

Система графиков временная, потом её переделаем целиком. Пока так.

- Новый график — на ECharts из `@/shared/ui/EChart`: `ChartFrame` → строка
  заголовка с `ChartToolbar` → `ChartCanvas`. Recharts `Chart` остаётся там, где уже
  стоит; новых графиков на нём не заводим и старые сами не переводим.
- `label` графика — что показано и за какой период («Оборот по неделям,
  1 год»), а не общее «График»: его читает скринридер.
- Пустой период — `Empty`, а не пустые оси.
- Точные значения важны — рядом таблица `ChartDataTable`: у canvas нет
  клавиатуры, и с графика число не скопировать.
- Период графика стоит по правилу `page.md`: общий для страницы — в шапке,
  свой — в панели графика.

```tsx
<ChartFrame>
  <div className="flex items-center justify-between gap-2">
    <h2>Оборот по неделям</h2>
    <ChartToolbar periods={PERIODS} period={period} onPeriodChange={setPeriod} />
  </div>
  <ChartCanvas label="Оборот по неделям, 1 год" option={option} />
</ChartFrame>
```

## Числа и даты

График пишет числа и даты так же, как таблица и плитка рядом: человек
сверяет их глазами, и «3679453» в подсказке при «3 679 453» в плитке
читается как другое число.

- Число в подсказке — с разрядами, как `FormatNumber` («3 679 453»).
  `ChartTooltipContent` и `EChart` делают это сами; свой `formatValue` или
  `valueFormatter` — только для денег, процентов и единиц, и тогда через
  `formatPriceText`, `formatPercentText`, `formatUnitText`.
- Ось значений — компактно, через `formatNumberText(value, { compact: true })`
  («3,5 млн»). `EChart` ставит это сам, у Recharts — `tickFormatter`.
- Ширину оси значений не зашиваем числом: у Recharts `YAxis width="auto"`; ECharts 6
  держит подписи в контейнере сам (`grid.outerBoundsMode` по умолчанию),
  `outerBoundsMode: 'none'` не ставим. Зашитая ширина обрезает подпись, как
  только числа вырастут. Ось категорий с длинными названиями — другое дело:
  там ширина и обрезка подписи задаются нарочно.
- Дата в подсказке — целиком, как у `DateTime`: «30.10.2026», через
  `formatDateTimeText(value, { show: 'date' })` в `formatLabel`. На оси —
  коротко, «30.10» (`mode: 'format', format: 'dd.MM'`): в окне до года год
  лишний. ISO `2026-10-30` на экран не
  выводим.
- Свой `toLocaleString`, `String(n)` и разбор даты руками в графике не
  пишем: берём текст из `Format*` и `DateTime`.

## Checklist

1. Новый график на ECharts, семейство `ChartFrame`.
2. `label` называет показатель и период.
3. Пустой период — `Empty`.
4. Где важны точные значения, рядом `ChartDataTable`.
5. Число в подсказке с разрядами, на оси значений компактно; ширина оси
   значений не зашита.
6. Дата в подсказке «30.10.2026», на оси «30.10»; ISO на экране нет.
7. Своего `toLocaleString`, `String(n)` и разбора даты в графике нет.
